# Z-FINANCE 1.0.0 - Automated Reminder System Guide

## Overview
The Reminder System automates alerts across personal tasks, payment deadlines, invoices, and team meetings.

## Channels & Types
- **Alert Types**: Personal, Customer, Invoice Payment, Task Deadline, Meeting Reminders.
- **Delivery Channels**: In-App Notifications, Email Queues, SMS Gateways, Push Notifications.
- **REST API Endpoints**:
  - `GET /modules/reminders/api/reminders.php?action=get_reminders`
