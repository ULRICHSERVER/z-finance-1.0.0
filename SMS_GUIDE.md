# Z-FINANCE 1.0.0 - SMS & WhatsApp Engine Guide

## Overview
Provides multi-provider SMS and WhatsApp API integration for automated SMS alerts and customer communication.

## Providers & Features
- **Supported Providers**: MTN SMS Gateway, Orange SMS, Twilio, WhatsApp Business Cloud API.
- **Automated Triggers**: 2FA OTP Verification codes, Invoice due reminders, Payment confirmations, and Project milestone updates.
