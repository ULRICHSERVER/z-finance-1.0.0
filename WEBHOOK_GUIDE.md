# Z-FINANCE 1.0.0 - Webhook Engine & Real-Time Event Dispatcher Guide

## Overview
Asynchronous HMAC-SHA256 signed event notifications dispatched to third-party webhooks upon key system events.

## Supported Events
- `invoice.created`, `invoice.paid`
- `expense.created`, `expense.flagged`
- `momo.disbursement.success`, `momo.collection.failed`
- `inventory.threshold_breach`
- `payroll.batch_completed`
