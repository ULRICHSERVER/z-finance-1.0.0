# Z-FINANCE 1.0.0 - File & Folder Permission Security Guide

## Security Architecture
Multi-layered RBAC controls ensure granular file security across private, shared, and organizational levels.

## Permission Levels
- **View**: Read-only document access.
- **Download**: Permission to download file assets.
- **Edit**: Upload new versions or update document metadata.
- **Share**: Generate internal or public share links with expiration & passwords.
- **Delete / Soft Delete**: Move files to Recycle Bin.
- **Approve / Sign**: Participating in review workflows and digital signatures.
