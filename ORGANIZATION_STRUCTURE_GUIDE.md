# Z-FINANCE 1.0.0 - Organization Structure Guide

## Overview
Defines hierarchy, department trees, management reporting chains, and corporate settings for multi-tenant deployments.

## Highlights
- **Departments**: Unlimited departments with manager assignments and member counting.
- **Reporting Lines**: Direct Manager to Employee hierarchy mapping.
- **REST API Endpoint**:
  - `GET /modules/departments/api/departments.php`
  - `POST /modules/departments/api/departments.php`
