# Z-FINANCE 1.0.0 - Barcode & QR Code Label Management Guide

## Overview
Integrated label generation for products, warehouse aisles, and fixed asset tags.

## Label Standards
- **Code 128 / EAN-13**: Standard product retail barcodes.
- **QR Codes**: High-density 2D barcodes containing product SKU, serial number, and warehouse location.
- **Thermal Label Printer Ready**: Print tags directly from the UI or scan using handheld mobile devices.
