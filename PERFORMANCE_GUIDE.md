# Z-FINANCE 1.0.0 - Performance & 360° Evaluation Guide

## Overview
KPI tracking, objective setting, and multi-rater 360° performance appraisal system.

## Features
- **360° Reviews**: Self-reviews, manager appraisals, and peer feedback.
- **KPI Scores**: Numerical scoring (1.00 - 5.00) mapped to bonus recommendations.
- **Promotion Workflow**: Performance-triggered career progression tracking.
