# Z-FINANCE 1.0.0 - Calendar Management Guide

## Overview
The Calendar System provides comprehensive event scheduling and time management capabilities for individuals, teams, businesses, and organizations.

## Key Features
- **Multiple Calendar Views**: Daily, Weekly, Monthly, Yearly, Agenda, Timeline, and Team Views.
- **Event Management**: Complete event lifecycle tracking with title, category, priority, start/end date and time, location, Google Meet/Video links, and notes.
- **Categories**: Meetings, Appointments, Training, Conferences, Workshops, Deadlines, Reminders, Holidays, Personal, and Business Events.
- **REST API Endpoints**:
  - `GET /modules/calendar/api/calendar.php?action=get_events`
  - `POST /modules/calendar/api/calendar.php?action=create_event`
