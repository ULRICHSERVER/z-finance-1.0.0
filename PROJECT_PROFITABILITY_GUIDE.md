# Z-FINANCE 1.0.0 - Project Profitability Guide

## Overview
Calculates project-level gross and net profitability by cross-referencing actual revenue (invoices & income) against actual expenses (labor, materials, overhead).

## Key Formulas
- **Actual Profit**: `Actual Revenue - Actual Cost`
- **Profit Margin %**: `(Actual Profit / Actual Revenue) * 100`
- **Cost Variance**: `Estimated Cost (Budget) - Actual Cost`
