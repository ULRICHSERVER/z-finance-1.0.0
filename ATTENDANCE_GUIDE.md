# Z-FINANCE 1.0.0 - Attendance & Shift Management Guide

## Overview
Automated time tracking using QR codes, manual check-in, biometric terminal support, and GPS mobile check-in.

## Capabilities
- **QR Code Check-In**: Instant personal QR code scanning for kiosks.
- **Biometric Integration**: API endpoints ready for fingerprint/face terminals.
- **Grace Periods & Late Tracking**: Auto-flagging check-ins beyond shift start + grace period.
- **Offline Syncing**: Local caching of check-in timestamps with background server queue synchronization.
