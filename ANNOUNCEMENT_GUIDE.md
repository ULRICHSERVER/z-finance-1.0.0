# Z-FINANCE 1.0.0 - Global Announcements Guide

## Overview
Allows Super Administrators and authorized controllers to broadcast system-wide notices, emergency warnings, and business updates.

## Broadcast Types
- **Global Notice**: Tenant-wide informational announcements.
- **Emergency Alert**: High-priority banner warning users of immediate system or security actions.
- **Maintenance Notice**: Scheduled server maintenance and downtime schedules.
- **REST API Endpoint**:
  - `GET /modules/announcements/api/announcements.php`
  - `POST /modules/announcements/api/announcements.php`
