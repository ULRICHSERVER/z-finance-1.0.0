# Z-FINANCE 1.0.0 - Storage Management & Quota Guide

## Storage Architecture
Real-time storage metering and quota enforcement across tenant workspaces.

## Features
- **Quota Allocation**: Configurable workspace limits (e.g. 10 GB default).
- **Storage Metrics**: Visual gauge displays real-time space usage, free space, and file count.
- **Compression & Cleanup**: Automated soft-delete purge policies and compression routines.
