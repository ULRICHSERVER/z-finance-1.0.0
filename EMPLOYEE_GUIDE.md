# Z-FINANCE 1.0.0 - Employee Management Guide

## Overview
The Employee Management System tracks complete lifecycle records for staff, contract personnel, consultants, interns, and volunteers across the enterprise.

## Core Features
- **Employee Profiles**: Employee ID, Code, User Account, Personal Details, Job Title, Department, Team, Manager, Employment Type, Joining Date, Biography, Skills, and Notes.
- **Employment Types**: Full Time, Part Time, Contract, Temporary, Intern, Volunteer, Consultant, Freelancer.
- **REST API Endpoint**:
  - `GET /modules/employees/api/employees.php`
  - `POST /modules/employees/api/employees.php`
