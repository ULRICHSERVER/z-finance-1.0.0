# Z-FINANCE 1.0.0 - White Label Branding & Custom Domain Guide

## Overview
How enterprise tenants customize logos, primary/secondary hex colors, login page headlines, invoice PDF headers, custom CSS, and vanity subdomains/custom domains.

## Configuration Attributes
- `primary_color`: Controls buttons, active state highlights, and primary banners.
- `secondary_color`: Accent color for badges and secondary interactive elements.
- `custom_domain`: Automated SSL certificate validation and CNAME verification engine.
