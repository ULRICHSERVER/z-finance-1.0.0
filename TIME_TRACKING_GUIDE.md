# Z-FINANCE 1.0.0 - Time Tracking Guide

## Overview
The Time Tracking Engine logs billable and non-billable employee working hours across projects and tasks.

## Core Features
- **Live Timer Widget**: Start and Stop timer with real-time counter.
- **Manual Time Entry**: Log hours worked with custom billable hourly rates.
- **Productivity & Employee Hours**: Calculates total time spent vs estimated hours.

## REST API Endpoint
`POST /modules/tasks/api/tasks.php` (Action: `log_time`)
