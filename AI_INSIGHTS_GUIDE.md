# Z-FINANCE 1.0.0 - AI Financial Insights & Recommendations Guide

## AI Financial Assistant Capabilities

The AI Financial Insights System scans tenant ledger records, expense categories, receivables, and recurring invoices to generate automated recommendations across 4 categories:

1. **Cost Reduction**: Detects sudden spikes in software subscriptions, cloud hosting, or administrative overhead.
2. **Income Opportunities**: Highlights clients nearing API/usage limits for upsell proposals.
3. **Cash Warning**: Identifies overdue receivables and aged invoices.
4. **Profit Strategy**: Provides growth re-investment suggestions when profit margins exceed targets.

## API Endpoints

### Get AI Insights
`GET /modules/ai_finance/api/insights.php?action=insights`

### Get Active Risk Alerts
`GET /modules/ai_finance/api/insights.php?action=alerts`
