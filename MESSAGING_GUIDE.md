# Z-FINANCE 1.0.0 - Messaging Guide

## Overview
The Internal Messaging System enables instant private and group communication across Users, Teams, Employees, Customers, and Suppliers.

## Core Features
- **Conversation Types**: One-to-One Chat, Group Chat, Team Chat, Project Chat, Customer Chat, Supplier Portal Chat.
- **Message Types**: Text Messages, Images, Documents, PDF Attachments, Voice Messages.
- **Real-time Interaction**: Message Reactions, Read Receipts, Delivery Status, Mute/Pin Conversations, Archive & Delete.
- **REST API Endpoint**:
  - `GET /modules/messages/api/messages.php?action=conversations`
  - `POST /modules/messages/api/messages.php`
