# Z-FINANCE 1.0.0 - Audit & Forensic Log Guide

## Overview
Immutable, append-only security audit log recording all user actions, system modifications, data exports, financial approvals, and administrative configuration changes.

## Log Schema Attributes
- `tenant_id`, `user_id`, `action_code`, `module_code`, `ip_address`, `details_json`, `created_at`.
