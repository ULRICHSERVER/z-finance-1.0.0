# Z-FINANCE 1.0.0 - Notification Center Guide

## Overview
The Notification Center consolidates system alerts, financial events, project status updates, CRM notifications, and security alerts in a centralized hub.

## Categories & Delivery Channels
- **Notification Categories**: System, Financial, Project, Customer, Supplier, Security, Admin.
- **Delivery Channels**: In-App Bell Notifications, SMTP Email, SMS Gateways, Browser Push Notifications, WhatsApp Business API.
- **REST API Endpoint**:
  - `GET /modules/notifications/api/notifications.php`
  - `POST /modules/notifications/api/notifications.php`
