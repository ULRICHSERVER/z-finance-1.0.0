# Z-FINANCE 1.0.0 - Multi-Factor Authentication (MFA) & Passkey Guide

## Overview
Comprehensive guide for configuring Time-Based One-Time Passwords (TOTP), SMS/Email OTPs, Passkeys, and emergency recovery code management.

## Key Protocols
- **TOTP**: SHA-1 / SHA-256 HMAC time-based token validation (Google Authenticator, Authy, YubiKey).
- **Recovery Codes**: Single-use 16-character alphanumeric backup keys.
- **Trusted Devices**: 30-day device cookie trust exemption with biometric passkey re-validation.
